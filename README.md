# Ahad's Study Space

A standalone, mobile-friendly study planner for Class XII UP Board + NEET 2027.

## Features
- Soft pink and cream responsive design
- Dashboard for Physics, Chemistry, Biology, General Hindi and English
- Chapter status preserved from Ahad's reported progress
- Checkboxes for concepts, questions/MCQs, board preparation and revision
- Daily calendar from 25 October to 15 December 2026
- Progress bars update automatically
- Progress and notes saved in the browser's localStorage
- Exportable JSON backup

## GitHub Pages setup
1. Upload `index.html` and `README.md` to a repository named `neet-planner`.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then Save.
5. After deployment, the site should be available at `https://YOUR-USERNAME.github.io/neet-planner/`.

## Notes
- Browser storage is device/browser-specific. Use **Daily notes → Export backup** to save a backup.
- Hindi and English chapter rows are syllabus placeholders until the exact prescribed book contents are confirmed.
- The 15 December finish date is an ambitious target; move unfinished tasks forward rather than doubling the next day's workload.
